# Catalog expansion imagery (p24–p150)

Added 2026-09-29. Every file here belongs to exactly one product (or one colour of a
variant family); no image is shared between products. Everything is stored locally — the
browser makes no third-party image requests.

## Illustrations (`*.svg`)

Flat studio-style illustrations generated for this demo catalog. They are not photos of
real merchandise: the fictional brands (Stride, Veloce, Kinetik, Urbano, Kairo, Terrah,
Nimbus, Sonora, Vortex, Voltra, Arcadia, Orion, Lumio, Nexa, Brava, Limpax, Belfiore,
Axion, Atlas, Hydra, Letra Viva) have no product photography, and variant colours must
match the colour sold. File names follow `<product>-<colour>.svg` for variant families
(the drawing uses that colour) and `<product>.svg` for single products. Book covers are
typographic covers of these public-domain editions.

used by ../../home and ../SOURCES.md. Downloaded 2026-09-29, re-encoded to WebP (max. 800 px).

photo (e.g. the AirPods photo shows the 3rd generation, so the listing is the 3rd generation).
